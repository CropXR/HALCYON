## MLflow integration

To setup logging to [MLFlow server of CropXR](https://mlflow.cropresilience.org) add the following lines to your `.bashrc`. The token can be generated [here](https://mlflow.cropresilience.org/oidc/ui/user).
```
export MLFLOW_TRACKING_URI="https://mlflow.cropresilience.org"
export MLFLOW_TRACKING_PASSWORD="YOUR_ACCESS_TOKEN"
export MLFLOW_TRACKING_USERNAME="YOUR_EMAIL"
```
